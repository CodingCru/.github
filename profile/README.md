# CodingCru

Minimal, production-ready boilerplates and small open-source tools.

## Packages

- **[django-cognito-auth](https://github.com/CodingCru/django-cognito-auth)** — AWS Cognito authentication core for Django

## Boilerplates

- **[django-nuxt-ssr-boilerplate](https://github.com/CodingCru/django-nuxt-ssr-boilerplate)** — Django + Nuxt 3 SSR (also works as SPA)
- **[fastapi-vue-spa-boilerplate](https://github.com/CodingCru/fastapi-vue-spa-boilerplate)** — FastAPI + Vue 3 SPA

## Tools & Projects

- **[google-storage-analyzer](https://github.com/CodingCru/google-storage-analyzer)** — Find what's eating your Google Drive, Gmail, and Photos storage — from the terminal
- **[perplex-image](https://github.com/CodingCru/perplex-image)** — Image puzzle game with drag-drop tiles, difficulty levels, and move tracking
